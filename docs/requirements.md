# 项目功能需求文档

## 1. 项目目标

开发一款跨平台桌面屏保应用，支持 macOS 与 Windows。用户输入出生年月日后，系统实时计算并展示退休时间，提供有趣、动态、美观的界面交互体验。

## 2. 核心功能

### 2.1 出生日期与时间

- 用户可通过日期时间选择器输入出生年月日时分。
- 支持清空与重新选择。
- 配置持久化于 `localStorage`，多窗口通过 `storage` / `BroadcastChannel` 同步。

### 2.2 退休日期计算

- **手动模式**：用户指定退休年龄（周岁，默认 60，可配置 30–100）。
- **预设模式**：按性别（男/女）与岗位类别（一般职工、管理/干部岗、特殊工种提前退休）选取简化政策表，自动得出有效退休年龄。
- **可选出生年月查表**（预设模式下）：按 **可配置规则包 JSON**（内置逐月 segment + override）计算退休月龄；支持 **在线规则包**（从远程 URL 拉取，**仅写入本地缓存** 后查表，不降级覆盖较新版本）、导入/导出/下载模板；精确到月，界面展示免责声明（非官方表格）。
- 出生时间或政策变更后立即重新计算退休目标时刻与倒计时。

### 2.3 退休时间与倒计时

- 显示退休日期时间（满**有效**退休年龄的同一时刻）。
- 显示距离退休的倒计时：年、月、日、时、分、秒。
- 倒计时数字变化时具备翻面/翻牌动画效果。
- 显示是否已到或已过退休时间，以及人生进度条（0–100%）；已退休时展示庆祝动效层（confetti + 文案）。
- **分享卡片**：一键导出 PNG 海报（出生/目标时刻、倒计时或已退休文案、规则包提示），供社交分享。

### 2.4 趣味化展示与屏保素材

- 动态动画（背景光球漂浮、卡片入场、倒计时卡片强调效果）。
- 支持上传多张背景图（IndexedDB 存 blob，配置存元数据），自动轮播；可配置间隔、填充方式、是否叠加倒计时。

### 2.5 快速显示/隐藏屏保

- 鼠标双击屏保空白处，或按 `F` 键，可快速显示/隐藏屏保（桌面端隐藏到托盘，浏览器端切换沉浸全屏）。
- 桌面端单击托盘图标可快速显示/隐藏窗口（双击仍为显示）。
- 双击 / 快捷键会避开齿轮入口等可交互元素，避免误触。
- 桌面端屏保页进入系统级全屏；`Esc` 隐藏到托盘。

### 2.6 退休里程碑提醒

- 后台可开启本地通知；提醒节点可在 **365 / 100 / 30 / 7 / 1 / 0** 等预设中勾选，并支持自定义天数与 120 字以内附言。
- 同一退休目标时刻下，每个 milestone 仅触发一次；目标变更后重新计发。
- **桌面端**：Electron `Notification`。
- **浏览器**：Web Notification API（需用户授权）。

### 2.7 界面主题

- 支持 **深色**、**浅色**、**跟随系统** 三种模式。
- 主题写入统一配置源，屏保页与后台配置页同步；浅色模式通过 `data-theme` 与 Ant Design 主题 token 联动。

## 3. 配置与架构约束

1. **单一数据源**：`RetirementConfig`（出生时间、手动年龄、政策、提醒、主题、图片与轮播）为屏保展示与 `#/admin` 后台的唯一来源。
2. **展示/配置分离**：屏保页只读；写入仅发生在后台配置页（及托盘跳转 admin）。
3. **有效年龄解析**：倒计时与进度条使用 `resolveEffectiveRetirementAge`，不覆盖用户保存的手动年龄字段，便于在预设/手动间切换。

## 4. 非功能需求

1. **跨平台**：macOS 与 Windows 开发与打包（Electron + electron-builder）。
2. **性能**：前端计算实时；动画流畅；图片数量上限与 object URL 生命周期管理。
3. **可维护性**：ESLint + Prettier；提交前 lint-staged；Monorepo（`apps/web` | `apps/server` | `apps/desktop`）。
