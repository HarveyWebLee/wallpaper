# 项目功能需求文档

## 1. 项目目标

开发一款跨平台动态壁纸应用，支持 macOS 与 Windows。在桌面图标层之下展示图片、视频与内置动态场景，并提供美观、易用的配置界面。

## 2. 核心功能

### 2.1 壁纸与桌面集成

- Windows：WorkerW 桌面层注入，壁纸显示在图标下方
- macOS：桌面层窗口级别，跨 Space 显示
- 多显示器：每个显示器独立壁纸窗口
- 托盘：暂停/恢复、重新应用、打开设置、退出

### 2.2 壁纸内容

- **图片壁纸**：JPG、PNG、WebP、GIF
- **视频壁纸**：MP4、WebM、MOV（循环播放，可调音量）
- **内置场景**：
  - 退休倒计时（翻牌动画）
  - 极光渐变
  - 粒子星空

### 2.3 配置与持久化

- 壁纸库导入与管理
- 出生日期 / 退休年龄（退休场景）
- 开机启动、启动时应用壁纸
- 性能模式（省电 / 平衡 / 高画质）
- 视频壁纸音量
- 设置本地持久化

### 2.4 界面

- 侧边栏导航：控制中心、壁纸库、内置场景、偏好设置
- 暗色玻璃拟态视觉，与翻牌倒计时风格统一

## 3. 非功能需求

1. 跨平台：Windows 与 macOS 开发与打包
2. 性能：壁纸层可节流、可暂停
3. 可维护性：ESLint + Prettier + TypeScript 严格检查

## 4. 后续迭代建议

- 按显示器单独分配壁纸（UI 完善）
- 全屏应用/游戏时自动暂停检测
- 壁纸轮播与定时切换
- 社区壁纸包导入
- HTML/WebGL 场景 SDK
